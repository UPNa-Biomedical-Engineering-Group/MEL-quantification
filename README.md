# MEL quantification

ImageJ/Fiji macros for quantifying marker expression level (MEL) in
haematoxylin-DAB immunohistochemistry (IHC) images. The method estimates,
within a defined tissue or tumour region, the area occupied by a selected
cellular compartment and the mean DAB signal in that compartment.

## Purpose and measurement definition

For each image, the macros:

1. define the region in which measurements are made;
2. separate haematoxylin and DAB using ImageJ's `H&E DAB` colour
   deconvolution vector;
3. segment the selected cellular compartment; and
4. measure compartment area and mean DAB intensity.

For mask-based analyses, the principal area measurements are:

```text
compartment area (um2) = measured compartment area (pixels) * r^2
compartment area (%)   = 100 * compartment area (um2) / region area (um2)
```

where `r` is the image scale in micrometres per pixel. Mean DAB intensity
is measured on the deconvolved DAB channel within the selected compartment.
The macros invert the DAB channel before measurement; therefore, the
reported value is the mean of the inverted DAB image used by the macro,
not an independently calibrated optical-density measurement.

## Processing options

The graphical launcher combines three choices:

| Choice | Available options | Meaning |
|---|---|---|
| Analysis mode | Single image, Batch mode | Process one image or all `.tif` files in a folder |
| Region to analyse | Whole tissue, ROI from mask, Manual ROI | Define the region used for segmentation and measurement |
| Structure | Nuclei, Cytoplasm, Membrane | Select the compartment to quantify |

Manual ROI is available only in single-image mode. The corresponding macro
files are:

| File suffix | Required input | Region definition | Mode |
|---|---|---|---|
| `_whole_tissue` | one original image | automatic tissue threshold | single image |
| `_tissue` | folder of original images | automatic tissue threshold | batch |
| `_single` | one original image and one label mask | external tumour mask | single image |
| `_ROI` | one original image | freehand ROI drawn by the user | single image |
| no suffix | folder of images and folder of label masks | external tumour mask | batch |

## What the algorithm does

### Nuclei

The haematoxylin channel is thresholded, holes are filled, a median filter
is applied, and watershed is used to separate touching objects. Objects
outside the selected region or outside the accepted particle-size range
are excluded. The resulting nuclear ROI is used to measure area and DAB
intensity.

### Cytoplasm

Nuclei are detected as above and dilated to avoid counting the nuclear
boundary as cytoplasm. Boolean operations between the selected region and
the dilated nuclear ROI produce the cytoplasmic ROI. Area and mean DAB
intensity are measured in that ROI.

### Membrane

The membrane workflow combines haematoxylin maxima with maxima derived
from strongly DAB-positive regions to generate watershed seeds. A
marker-controlled watershed is applied to the inverted DAB image inside
the selected region. Watershed boundaries are eroded and filtered by
minimum object size before membrane area and mean DAB intensity are
measured.

The deconvolved `blue` and `brown` images, nuclei masks, cytoplasm ROIs,
watershed seeds, and membrane masks are intermediate images generated by
the macros. They are not additional input files.

## Input data

### Original IHC image

The original image is the RGB brightfield image containing haematoxylin
and DAB staining. It is the source image for all measurements.

Required conditions:

- RGB image compatible with the `H&E DAB` colour-deconvolution vector;
- `.tif` extension for batch processing (the current code checks for
  lowercase `.tif`);
- the same pixel dimensions as its label mask when mask mode is used; and
- a known pixel scale, supplied through `Ratio micra/pixel`.

Do not provide a deconvolved channel, a binary nuclei mask, or a JPEG
quality-control overlay as the original image.

### External tumour label mask

An external mask is required only for **ROI from mask**. It is a label
image, not a screenshot and not a copy of the RGB image. Each pixel stores
an integer region label, such as background, non-tumour tissue, or tumour.

For batch mode, the image and mask must have identical filenames and
extensions and must be stored in separate, parallel folders:

```text
images/
|-- case_001.tif
`-- case_002.tif

masks/
|-- case_001.tif
`-- case_002.tif
```

For `case_001.tif`, the batch macros open the image from `images/` and the
mask from `masks/`. The mask must therefore be present under exactly the
same filename. The single-image macros ask for the original image first
and the corresponding segmentation image second.

## Parameters

The following are the parameters exposed by the current macros. The
defaults are the values encoded in the scripts and are starting values,
not universal biological constants.

| Parameter | Compartments | Function | Default |
|---|---|---|---:|
| `Ratio micra/pixel` (`r`) | all | Converts pixel lengths to micrometres and pixel areas to um2 | 0.502 |
| `Tumor label` (`labT`) | mask modes | Label selected as tumour after the internal subtraction | 1 |
| `Nuclei threshold` (`thBlue`) | nuclei, cytoplasm | Upper threshold on the deconvolved haematoxylin channel | 190 nuclei; 100 cytoplasm; 140 membrane |
| `Min nuclei size` (`minCellSize`) | nuclei, cytoplasm | Minimum accepted nuclear particle area in pixels | 30 |
| `Max nuclei size` (`maxCellSize`) | nuclei, cytoplasm | Maximum accepted nuclear particle area in pixels | 15000 |
| `Prominence for nuclei detection` (`prominence`) | membrane | Prominence used by `Find Maxima` for seed generation | 5 |
| `GLUT threshold` (`thBrown`) | membrane | Threshold for strongly DAB-positive regions used in seed generation | 130 |
| `Min membrane size` (`minMembSize`) | membrane | Minimum accepted membrane particle area in pixels | 50 |

Some cytoplasm scripts also contain additional thresholds for channel-based
classification. These values are defined in the relevant script and
should be reported with the analysis if they are changed from their
validated settings.

## Outputs

The most complete, currently operational export is implemented in the
three mask-based batch macros:

- `nuclei/nuclear.ijm`;
- `cytoplasm/cytoplasm.ijm`; and
- `membrane/membrane.ijm`.

These macros save a Results table as `QuantificationResults.xls` and
append one row per analysed image. Depending on the compartment, columns
include:

- image identifier (`Label`);
- selected region area (`Tumour area (um2)` where a tumour mask is used);
- compartment area as a percentage of the selected region;
- mean DAB intensity in the compartment (`Iavg nuclei`,
  `Iavg cytoplasm`, or `Iavg membrane`); and
- additional classification columns in variants that implement them.

The mask-based batch workflows create these folders inside the selected
mask directory:

```text
Quantification_results/
|-- QuantificationResults.xls
`-- case_001_analyzed.jpg

Quantification_results_cytoplasmic/
|-- QuantificationResults.xls
`-- case_001_analyzed.jpg

Membrane_segmentations/
`-- case_001_membraneSegmentation.jpg
```

The JPEG files are quality-control overlays in which the detected
compartment is drawn in red on the original image. 

## Requirements

- Make sure MorphoLibJ is installed in your ImageJ/Fiji instance (you can install it from the ImageJ update site or by copying the MorphoLibJ jar into plugins/)

## Installation

1. Download or clone this repository:

   ```bash
   git clone https://github.com/UPNa-Biomedical-Engineering-Group/MEL-quantification.git
   ```

2. Keep `run_gui.ijm` and the `nuclei`, `cytoplasm`, and `membrane`
   directories together. Place them in a Fiji macro directory, for
   example:

   ```text
   Fiji.app/macros/MEL_quantification/
   ```

3. In Fiji, choose `Plugins > Macros > Run...` and open `run_gui.ijm`.
   Select the analysis mode, region definition, and compartment in the
   dialogs.

If Fiji reports that a macro cannot be found, place the three compartment
directories directly inside `Fiji.app/macros/`, restart Fiji, and run the
launcher again. The launcher uses ImageJ macro command names to call the
compartment scripts.
